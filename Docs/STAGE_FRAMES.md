# Границы этапов и контрольные точки в кадрах прогона

Таблица снята один раз, чтобы прицельные проверки (босс этапа, тяжёлые сцены, разрывы строк, звук)
не искались перебором. Источник — прогон модели `rtype_check.py --invincible --autofire 400`
со стартом игры на кадрах 330/331 (`--keys 330:331:space`), журнал `--stage-log`.

Кадры относятся именно к этому сценарию: неуязвимость, автоогонь, без движения. При другом вводе
игра идёт иначе, но порядок этапов и значения прогресса те же — они заданы ROM.

## Контрольные точки ROM

Таблица `ES:$87FA` (16 записей по 14 байт, читается из эталонной машины по физическому адресу
`$187FA` при `ES = $1000`): слово +0 — прогресс (`$2F4B` рабочего ОЗУ), слова +2/+4 — смещения
источника полос переднего и дальнего слоёв, +12 — номер этапа. Именно с этих значений прогресса ROM
возрождает игрока после смерти, то есть это и есть подуровни.

|---|---|---:|---|
| 1 | `$0600` | 363 | начало этапа |
| 1 | `$06C0` | 747 | |
| 1 | `$0A80` | 2667 | |
| 1 | `$0FC0` | 5355 | |
| 2 | `$1500` | 8890 | начало этапа |
| 2 | `$1A40` | 11578 | |
| 3 | `$1F80` | 17329 | начало этапа, точка одна |
| 4 | `$2A00` | 27697 | начало этапа |
| 4 | `$2F40` | 30385 | |
| 5 | `$3480` | 36357 | начало этапа |
| 5 | `$3AC0` | 39557 | |
| 6 | `$3F00` | 44835 | начало этапа |
| 6 | `$4540` | 48035 | |
| 7 | `$4980` | 52661 | начало этапа |
| 7 | `$4F00` | 55477 | |
| 8 | `$5400` | 62198 | начало этапа, точка одна |

Машинные данные — `Build/Stages/stage_points.json` (этап, прогресс, кадр) и `Build/Stages/stage_marks.json`
(полный журнал смен прогресса по кадрам).

## Как снять заново

```
python Source/Tools/rtype_check.py --frames 70000 --keys 330:331:space --autofire 400 --invincible \
       --render "" --stage-log Build/Stages/stage_marks.json
```

Прогон занимает около десяти минут и заодно служит полной сверкой с эталоном: память V30, вызовы
платформы, записи TSFM и состояние мелодий сравниваются каждый кадр (проверено 21 сентября 2026 —
расхождений нет на всех восьми этапах).

## Что из этого следует для проверок

- Босс этапа — ближе к концу отрезка до следующего начала; например, корабль этапа 3 искать между
  кадрами 17 329 и 27 697.
- Тяжёлые по выводу сцены этапа 2 (разрывы строк) — кадры 8 890…17 329; замеры цены строки FT812
  сняты на кадрах 9 000…13 500.
- Прогресс `$2F4B` растёт на единицу каждые два кадра прогона, поэтому по нему легко пересчитать
  кадр любой промежуточной позиции этапа.
