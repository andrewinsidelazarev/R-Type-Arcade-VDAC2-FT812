# Карта памяти R-Type VDAC2

Актуализируется при каждой опорной версии (правило проекта, как в HMM2).
Числа ниже соответствуют сборке из `pre-releases/2026-08-06 v001`.

## RAM_G (FT812, 1 МБ)

| Диапазон | Размер | Содержимое | Кем генерируется |
|---|---|---|---|
| `$000000…$0078AB` | 30 892 Б | объекты M72 в ARGB4444: R-9, выхлоп, обычный выстрел, снаряд Wave Cannon — 17 ассетов | `m72_sprite_assets.py` |
| `$0078AC…$09D8AB` | 614 400 Б | слой тайлов Stage 1, RGB565 640×480 (офлайн xBRZ ×6 → Lanczos) | `m72_scene.py` + `xbrz_offline.py` |
| `$09D8AC…` | — | свободно (скролл, враги, HUD, остальные уровни) | — |

Итого занято 645 292 Б. Адреса конкретных объектов — в
`Source/ASM/generated_m72_sprites.inc`, параметры фона — в
`generated_spritepages.inc` (`ARCADE_BG_RAMG`, `ARCADE_BG_STRIDE` и далее).

Спрайты хранятся в ARGB4444 (2 байта/пиксель), фон — в RGB565 (2 байта/пиксель,
без альфы).

## Страницы SPG

| Страницы | Содержимое |
|---|---|
| `#05` | `Build/Core.bin` — ядро по адресу `#5000` |
| `#10…#11` | блоб объектов M72 (2 страницы), заливается в RAM_G при старте |
| `#12…#37` | слой тайлов Stage 1 (38 страниц) |
| `#38` | PCM выстрела для General Sound: беззнаковое 8-битное моно 11 025 Гц, 4 096 Б |

Список страниц и `spgbld_rtype.ini` генерирует `split_sprites.py`: вести их
вручную — гарантированный рассинхрон при изменении ассетов.

## Память Z80

| Адрес | Содержимое |
|---|---|
| `#4000` | таблица векторов IM2 |
| `#41F3…#41F6` | ширина и высота логического кадра для модулей ввода |
| `#4200…` | резидентные переменные: счётчик кадров, состояние ввода, позиция и состояние R-9, таймеры |
| `…#4EFF` | стек |
| `#4F00` | резидент SPG-загрузчика |
| `#5000…` | ядро: код и резидентные данные, страница `#05` (слот 1) |
| `#B000…#BFFF` | буфер списка команд копроцессора (`CMD_ADDRESS_PTR`, слот 2) |

Позиции игрока — логические Q16.8 в пространстве 640×480; в вершины дисплей-листа
идут FT-единицы 1/8 физического пикселя (`VERTEX_FORMAT 3`), см. `Docs/PORT_PLAN.md`.
